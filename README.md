# EarnX Android Starter (Prototype v1)

## Included
- Kotlin + Jetpack Compose Android Studio project
- Red/black EarnX interface
- Home, Tasks, Wallet and Profile tabs
- Local demo points and daily check-in
- Demo withdrawal request form

## Important
This is a UI/interaction prototype only. Points are simulated and have no cash value.
No login backend, real ad network, task verification, referral tracking, admin panel,
KYC, UPI payout provider, or real payment processing is connected.

## Build
1. Install Android Studio (current stable) on a computer.
2. Open this folder as a project.
3. Let Gradle sync complete (internet required for dependencies).
4. Choose Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Install the generated debug APK on your Android phone.

Package: com.earnx.app
Minimum Android: 7.0 (API 24)
